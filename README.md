Кейс-задача № 4. Сила драконьей стаи.

Сила стаи равна произведению числа голов всех драконов. Известно суммарное
число голов N (0 < N < 100), у одного дракона не более 7 голов.
Требуется найти максимально возможную силу стаи.

Математически: разбить натуральное число N на натуральные слагаемые,
каждое из которых не больше 7, так, чтобы их произведение было наибольшим.

Метод решения - динамическое программирование:
    best[0] = 1
    best[s] = max(k * best[s - k]) по всем k от 1 до min(7, s),
где best[s] - максимальная сила стаи, в которой всего s голов,
а k - число голов у "последнего" дракона.
